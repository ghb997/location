# 1.1.0 中文版变更

- 自动发现本机 RemotePairing 服务端口，提供手动端口、实际服务检查和脱敏诊断分享。
- 为底层操作增加超时等待提示，保持定位写入与停止清除顺序；清除失败后重新连接重试，应用重开后提醒未确认的恢复。
- 网络变化后验证连接并尝试恢复，路线断线保持暂停，恢复后由用户继续。
- GPX 保留轨迹名称和分段，支持选择轨迹和起始分段，分段之间不自动插值或连线。
- 路线支持进度、暂停、继续和显式下一段；采用单调时钟，处理通信耗时和后台执行停滞。
- 模拟期间可以准备并应用新目标，停止按钮独立保留；搜索、道路请求与文件导入避免过期结果覆盖新操作。
- 增加明确的 WGS-84 / GCJ-02 输入与独立地图、服务兼容设置，默认沿用系统行为。
- 收藏升级保留旧数值并备份，稳定 ID 不随坐标修正变化；旧数据可逐项预览修正和撤回。
- 分开前台、后台定位权限，显示系统定位时间与状态；停止后释放持续保活资源。
- 完整补充中英文提示，构建与 IPA 校验从工程配置读取版本。

自动化结果以发布对应提交的 Actions 记录为准。当前未连接用户设备，真机定位、配对、停止恢复、后台耗电和界面视觉验收均见兼容性记录。
