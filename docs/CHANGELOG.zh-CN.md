# 1.2.0 location 中文版变更

版本 1.2.0，构建号 7，发布标签 `v1.2.0-zh.1`。应用显示名称改为 **location**，Bundle ID 保持 `com.ghb997.location`，最低系统仍为 iOS 18，支持 iPhone 与 iPad。

- 统一地图搜索、状态条、工具栏、底部操作区与引导页的通透玻璃风格。iOS 26 及以上使用原生 Liquid Glass，iOS 18–25 使用半透明材质；摇杆独立悬放，避免整个操作区被放大。
- 玻璃面板响应“降低透明度”和“增强对比度”；相关交互及引导动画响应“减少动态效果”。补足触摸区域和地图标记的 VoiceOver 操作，调整大字号操作按钮排列及 iPad 内容宽度。
- 引导页支持滚动和较大字号，应用及配对提示中的可见名称同步为 location，保留上游 Locus 项目和许可署名。
- 收藏和最近记录区分“空列表”与“读取失败”，阻止损坏数据被新增操作静默覆盖；新增原始数据导出、恢复可读备份及保留原始数据后新建列表的入口。
- 将待应用目标的选择版本集中到会话模型。地图点选、搜索、手动输入与收藏选择共同更新版本，迟到搜索结果不能覆盖更新的目标。
- 停止清除失败后，重连会重新发现并探测服务端口，避免继续使用重启前的端口；恢复过程仅重新连接和清除，不重新写入旧坐标。
- 保存路线草稿、活动路线与已确认进度；重新打开后保持暂停，完成的路线仍为完成状态。存在未确认的定位恢复标记时，先处理恢复，再由用户继续路线。
- 将路线显示坐标和距离准备移出反复刷新的视图计算；按路线及坐标设置缓存，保留原始点和分段供播放与 GPX 导出使用。
- 诊断增加有数量上限的脱敏事件历史，保留错误与恢复顺序，避免成功心跳覆盖先前故障。导出不包含配对密钥、PIN、设备身份或精确坐标。
- 配对保活音频处理中断和音频服务重置，失败时给出提示；该选项仍默认关闭，配对结束或取消后释放资源。
- 隐私文案说明收藏、最近记录和路线进度保存在本机，地图显示、地点搜索与道路规划会请求 Apple 地图服务；应用不设账号或使用统计服务。
- 增加收藏损坏恢复、跨入口目标竞争、动态端口恢复、路线存档及 50,000 点显示准备等回归用例；IPA 文件名前缀改为 `location`，版本仍从工程配置读取。

本版本的自动测试、Release 构建与成品校验结果以对应提交的 Actions 记录及[构建记录](BUILD.zh-CN.md)为准。真机设备尚未确定；配对、系统定位恢复、液态玻璃实际显示、锁屏及一小时后台耗电仍待验收，详见[兼容性记录](COMPATIBILITY.zh-CN.md)。50,000 点用例用于验证数据处理与缓存行为，不代表已完成设备帧率、内存或耗电测试。

# 1.1.1 中文版变更

版本 1.1.1，构建号 6，Bundle ID 保持 `com.ghb997.location`。

- 修复长时间断网、三次重试耗尽后，端口探测成功却无法恢复定位心跳的问题。
- 增加恢复连接修复入口，允许补充配对文件及更新隧道 IP／端口；恢复标记保留到清除成功，修复期间禁止新模拟。
- 修复旧路线遮住新草稿预览，以及慢搜索结果覆盖导入／所选路线起点的竞争问题。
- 停止后获取新系统定位增加有限重试与超时状态，避免缓存定位被丢弃后没有后续反馈。
- 增加实际会话控制器集成测试、路线预览与目标竞争测试、定位获取生命周期测试。

真机配对、系统位置恢复、锁屏与一小时后台测试仍待设备确认，不以自动测试替代真机结论。

# 1.1.0 中文版变更

- 自动发现本机 RemotePairing 服务端口，提供手动端口、实际服务检查和脱敏诊断分享。
- 为底层操作增加超时等待提示，保持定位写入与停止清除顺序；清除失败后重新连接重试，应用重开后提醒未确认的恢复。
- 网络变化后验证连接并尝试恢复，路线断线保持暂停，恢复后由用户继续。
- GPX 保留轨迹名称和分段，支持选择轨迹和起始分段，分段之间不自动插值或连线。
- 路线支持进度、暂停、继续和显式下一段；采用单调时钟，处理通信耗时和后台执行停滞。
- 模拟期间可以准备并应用新目标，停止按钮独立保留；搜索、道路请求与文件导入避免过期结果覆盖新操作。
- 增加明确的 WGS-84 / GCJ-02 输入与独立地图、服务兼容设置，默认沿用系统行为。
- 收藏升级保留旧数值并备份，稳定 ID 不随坐标修正变化；旧数据可逐项预览修正和撤回。
- 分开前台、后台定位权限，显示系统定位时间与状态；停止后释放持续保活资源。
- 完整补充中英文提示，构建与 IPA 校验从工程配置读取版本。

自动化结果以发布对应提交的 Actions 记录为准。当前未连接用户设备，真机定位、配对、停止恢复、后台耗电和界面视觉验收均见兼容性记录。
