# 1.3.0 location 地点确认与连接指引变更

版本 1.3.0，构建号 9，发布标签 `v1.3.0-zh.1`。应用名称保持 **location**，Bundle ID 保持 `com.ghb997.location`，最低系统仍为 iOS 18，支持 iPhone 与 iPad。

- 新增“待应用位置”卡片，集中显示所选地点的名称、可用地址、WGS-84 坐标和收藏状态。卡片与状态栏的当前模拟位置分开维护，定位心跳不会覆盖准备应用的地点信息。
- 从“地点”选择收藏或最近记录后，只返回地图预览，不再立即定位；核对卡片后需明确点击“定位到选点”。清除卡片只取消待应用目标，停止当前模拟仍使用独立的“停止”按钮。
- 搜索、收藏、路线起点等入口同步目标元数据；手动选点或拖动时清除不再匹配的名称和地址。迟到或无效的选择结果不能改写更新的目标信息。
- 地图相机根据顶部浮层、底部操作区和可用视图尺寸留边，为目标与路线安排显示范围；异步搜索或路线准备完成时，尊重用户期间主动拖动的地图视野，不再无条件抢回镜头。
- 状态栏新增连接指引入口，按配对、服务检测、连接中、底层等待、恢复未确认和运行中等状态显示处理步骤，并可直接跳到相应设置区。服务可达与开发者服务就绪保持区分；正常模拟期间的持久恢复标记不会被误报为恢复失败。
- 打开指引只显示说明，不自动检测或写入位置。连接检测、恢复操作需要明确点击，并继续遵循忙碌与底层等待门禁。
- 结合 wloc 的信息卡片和分步骤说明调整视觉层次，统一浅色卡片、次要文字、按钮间距和紧凑操作区。短内容贴近底部，受限高度或大字号下将信息与次要操作放入滚动区，停止按钮保留在滚动区外。
- 保留 iOS 26 原生 Liquid Glass、iOS 18–25 材质兼容和现有 idevice 定位架构；未引入 wloc 的证书代理、外部位置 URL 或 BD-09 输入。

本轮 164 项自动测试、Release 构建及 IPA 校验通过；iPhone／iPad 各 7 个场景，共 14 张组件截图已完成检查，详见[构建记录](BUILD.zh-CN.md)。预览使用实际生产组件、合成地图和模拟会话；受限高度场景不等同于实际横屏或键盘测试。真机 MapKit 交互、VoiceOver、横屏、网络切换、配对与定位恢复及一小时后台运行仍待验收，详见[兼容性记录](COMPATIBILITY.zh-CN.md)。

# 1.2.1 location 浅色液态玻璃变更

版本 1.2.1，构建号 8，发布标签 `v1.2.1-zh.1`。应用名称保持 **location**，Bundle ID 保持 `com.ghb997.location`，最低系统仍为 iOS 18，支持 iPhone 与 iPad。

- 固定浅色外观，统一地图控件、设置与路线弹层、首次引导、启动背景和彩蛋页面；系统采用深色模式时，应用界面仍保持浅色。
- 调整玻璃表面的层次与透视感。iOS 26 及以上使用系统原生 Liquid Glass，iOS 18–25 使用公开半透明材质、细渐变边缘和轻投影作为兼容效果。
- 将地图底部操作拆成独立悬浮胶囊，移除重复的玻璃底托，保留控件之间可见的地图；统一搜索、状态、工具栏和摇杆的圆角、留白与表面风格。
- 使用深色文字、较深的青绿色主色和明确的停止颜色，改善浅背景上的字色对比；降低透明度时采用实色表面，增强对比度时加强边缘，减少动态效果时收敛相关动画。
- 为辅助功能大字号下的操作区加入滚动范围，保持按钮可达；保留 iPad 内容宽度限制，并调整搜索结果与地图操作区的空间分配。
- 检查用户提供的五个设计参考，取其悬浮布局、清晰选中状态、细边缘和轻投影等视觉原则。没有复制参考项目的代码、图片、着色器或引入依赖，也没有采用其中的私有玻璃 API，详见[设计参考记录](GLASS-REFERENCES.zh-CN.md)。

本版本 144 项自动测试、Release 构建、IPA 校验及 iOS 26.2 下的 8 张生产 UI 组件截图检查已完成，详见[构建记录](BUILD.zh-CN.md)和[兼容性记录](COMPATIBILITY.zh-CN.md)。模拟器检查使用实际生产 UI 组件、合成地图背景及模拟会话状态；它不运行完整应用的定位／配对链路，也不替代真机验收。设备仍未确定，配对、定位恢复、VPN 切换及一小时后台运行保持待测。

# 1.2.0 location 中文版变更

版本 1.2.0，构建号 7，发布标签 `v1.2.0-zh.1`。应用显示名称改为 **location**，Bundle ID 保持 `com.ghb997.location`，最低系统仍为 iOS 18，支持 iPhone 与 iPad。

- 统一地图搜索、状态条、工具栏、底部操作区与引导页的通透玻璃风格。iOS 26 及以上使用原生 Liquid Glass，iOS 18–25 使用半透明材质；摇杆独立悬放，避免整个操作区被放大。
- 玻璃面板响应“降低透明度”和“增强对比度”；相关交互及引导动画响应“减少动态效果”。补足触摸区域和地图标记的 VoiceOver 操作，调整大字号操作按钮排列及 iPad 内容宽度。
- 引导页支持滚动和较大字号，应用及配对提示中的可见名称同步为 location，保留上游 Locus 项目和许可署名。
- 收藏和最近记录区分“空列表”与“读取失败”，阻止损坏数据被新增操作静默覆盖；新增原始数据导出、恢复可读备份及保留原始数据后新建列表的入口。
- 将待应用目标的选择版本集中到会话模型。地图点选、搜索、手动输入与收藏选择共同更新版本，迟到搜索结果不能覆盖更新的目标。
- 停止清除失败后，重连会重新发现并探测服务端口，避免继续使用重启前的端口；恢复过程仅重新连接和清除，不重新写入旧坐标。
- 保存路线草稿、活动路线与已确认进度；重新打开后保持暂停，完成的路线仍为完成状态。存在未确认的定位恢复标记时，先处理恢复，再由用户继续路线。
- 将路线显示坐标和距离准备移出反复刷新的视图计算；按路线及坐标设置缓存，保留原始点和分段供播放与 GPX 导出使用。
- 诊断增加有数量上限的脱敏事件历史，保留错误与恢复顺序，避免成功心跳覆盖先前故障。导出不包含配对密钥、PIN、设备身份或精确坐标。
- 配对保活音频处理中断和音频服务重置，失败时给出提示；该选项仍默认关闭，配对结束或取消后释放资源。
- 隐私文案说明收藏、最近记录和路线进度保存在本机，地图显示、地点搜索与道路规划会请求 Apple 地图服务；应用不设账号或使用统计服务。
- 增加收藏损坏恢复、跨入口目标竞争、动态端口恢复、路线存档及 50,000 点显示准备等回归用例；IPA 文件名前缀改为 `location`，版本仍从工程配置读取。

本版本的自动测试、Release 构建与成品校验结果以对应提交的 Actions 记录及[构建记录](BUILD.zh-CN.md)为准。真机设备尚未确定；配对、系统定位恢复、液态玻璃实际显示、锁屏及一小时后台耗电仍待验收，详见[兼容性记录](COMPATIBILITY.zh-CN.md)。50,000 点用例用于验证数据处理与缓存行为，不代表已完成设备帧率、内存或耗电测试。

- 完整补充中英文提示，构建与 IPA 校验从工程配置读取版本。
